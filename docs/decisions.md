# Решения

Текущий набор решений в силе. Одна запись на решение; когда решение меняется —
запись правится на месте, историю держит git.

## parse

### Дефолтные значения параметров

Decided: `parse()` дозаполняет `params` дефолтами объявленных параметров — после
разбора аргументов, только для тех имён, которых в `params` ещё нет, со
приведением к типу параметра. Дефолт из паттерна (`--concurrency -c number 4`)
конвертируется в момент `.param()`, поэтому `Param.defaultValue` хранит уже
типизированное значение, а негодный дефолт падает на месте объявления, а не при
разборе чужой командной строки.

Because: грамматика `--name [-s] <type> [default]` обещала это в README, и оба
потребителя с параметрами — claww и dispute — написали дефолт в паттерне раньше,
чем выяснили, что он не работает. Их `??` и `||` в коде — след бага, а не выбор.

Not chosen: выкинуть дефолты совсем и оставить их приложению
(`params.format ?? "md"`). Честнее по информации — `undefined` означал бы «не
передавали», и `params` оставался бы протоколом argv. Отвергнуто: требует
вычистить `[default]` из грамматики, README и шести объявлений, а выигрыш
проявляется только в сценарии «CLI поверх конфиг-файла», которого нет ни в
dapes, ни в claww, ни в dispute.

Known cost: `params` не различает «передал `-c 4`» и «промолчал». Если появится
конфиг-файл под CLI, подставленный дефолт будет молча бить значение из конфига —
понадобится провенанс значения (`ValueSource` у clap,
`getOptionValueSource` у commander).

Deferred: печать дефолта в `--help`. У claww руками вписаны в описания только
вычисляемые дефолты (`stdout`, `cwd`, `claww.out.<ext>`), которые статический
литерал в паттерне не удержит; у `--format string md` со статическим дефолтом
в описании ничего не вписано. Спрос не доказан.

### Форма результата parse

Decided: `parse()` всегда возвращает глобальный блок первой записью — и когда
передан `[globalBlock]`, и когда переданы блоки верхнего уровня, которые
оборачиваются в синтетический корень.

Because: одна форма результата вместо двух, индексы не зависят от того, как
вызвали `parse`.

Not chosen: сигнатура `parse(args, root: Block)` без эвристики
`globalBlockProvided` — ломает вызов в dapes и все примеры README; эвристика
оставлена только для выбора корня.

### Команды раньше позиционных

Decided: токен сначала сопоставляется с командами текущего блока, и только если
не совпал — идёт в позиционный аргумент.

Because: так уже работал `parse`, и линк команды опирается на это правило.

Known cost: файл с именем команды (`build`) позиционным не передать. Выход —
разделитель `--`, которого пока нет.

## cli

### Линк глобальной команды

Decided: `new Cli({ commandLink: "run" })` связывает глобальную команду с
командой `run`, на низком уровне — поле `Block.link` с именем потомка. Разбор
входит в слинкованную команду, когда токен не команда и не свободный глобальный
позиционный; когда флага нет у глобального блока, но есть у слинкованного; когда
аргументы закончились без команды. Флаг ищется сначала у глобального блока,
потом у слинкованного. Линк на несуществующую команду падает при `parse`;
`.action()` на глобальном блоке вместе с `commandLink` падает при объявлении.

Because: закрывает позиционные аргументы глобальной команды без собственных
позиционных у корня — это default command из commander и `$0` из yargs. Порядок
«сначала глобальный» не даёт общему имени флага угнать явную команду:
`mycli --verbose build` запускает `build`, даже если у `run` тоже есть
`--verbose`.

Not chosen: сначала слинкованный — `mycli --verbose build` уходил бы в `run`, и
`build` становился бы его позиционным. Запрет общих имён между корнем и
слинкованной командой — снимает вопрос порядка, но не выбран.

Known cost: после входа в линк глобальные флаги больше не принимаются —
`mycli --tag beta --debug app.ts` падает с `Unknown param --debug`, а
`mycli --debug --tag beta app.ts` работает. В группе коротких флагов (`-tv`)
блок выбирается по первой букве.
`arg` у записи слинкованной команды — её имя (`"run"`), хотя пользователь его не
набирал. Через `.block()` линк для вложенной группы не задать — только через
`Block.link` на низком уровне.
